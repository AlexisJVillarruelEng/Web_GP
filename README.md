
# SISTEMA INTERNO WEB | GPROMEC

Creacion de Intranet con Vue y Quasar para la gestión de matrices IPERC, Trabajadores, Firmas. Conectado a Backend interno por Rest API.

## Características Principales

- 📋 **Gestión de trabajadores:** listar, asignar y actualizar su ubicación actual.  
- 🏗️ **Gestión de Proyectos:** registro y consulta de Matriz IPERC.  
- 📦 **Gestión de Clientes:** listar, insertar y actualizar clientes para la visualización de las Matrices.  
- 🔄 **Historial de Archivos:** seguimiento y descarga de archivos registrados.   
- ☁️ **Conexión con API :** operaciones asincrónicas seguras y rápidas (insert, select, update).  
  

## Stack

**Cliente (Vue , Quasar):** JavaScript, HTML, Css, Quasar, Vue, Pinia, async/await  
**Backend / Servicios:** API REST.
